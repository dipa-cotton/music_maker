# Music Maker

this is my music maker! it's a 3 part midi keyboard/synth that has a LOT of thought put into it. It's able to connect using magnetic pogo connectors, has 2 outputs, communicates via xiao nrf5820, and has so so so many switches, sliders, and rotary encoders!
